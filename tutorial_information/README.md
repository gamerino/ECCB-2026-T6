# Tutorial Programme

## Overview

**Making the most of cis-regulatory annotations for genome-scale analysis** is a full-day, hands-on tutorial introducing the concepts, resources, and practical workflows required to explore, interpret, and analyse *cis-regulatory elements* (CREs) using publicly available epigenomic datasets and regulatory annotation resources.

The tutorial combines conceptual lectures, guided exploration of community resources, reproducible analyses in **R** or **Python**, genome browser visualisation, and an integrative case study focused on the interpretation of non-coding variants. Participants will learn how regulatory elements are inferred from epigenomic assays such as ATAC-seq, DNase-seq, and histone ChIP-seq, how different regulatory annotation frameworks complement one another, and how to integrate multiple sources of evidence into reproducible genomic analysis workflows.

## Learning Workflow

The tutorial follows a progressive workflow in which participants:

1. Build a conceptual understanding of regulatory elements and the epigenomic evidence used to infer them.
2. Explore regulatory annotations using community resources including [Ensembl Regulation](https://regulation.ensembl.org/) and [ENCODE SCREEN](https://screen.wenglab.org/).
3. Retrieve and analyse regulatory annotation files using reproducible workflows in **R** or **Python**.
4. Visualise multiple evidence layers using the **Integrative Genomics Viewer**, [IGV](https://igv.org/).
5. Integrate all sources of evidence to interpret regulatory regions and prioritise candidate non-coding variants.
