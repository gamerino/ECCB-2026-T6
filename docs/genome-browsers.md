# Genome Browsers and Regulatory Resources

Throughout this tutorial, participants will explore regulatory annotations and epigenomic datasets using several community resources and genome browsers.

Although **IGV** is the only application that requires installation, we encourage participants to familiarise themselves with the web resources before the tutorial.

| Resource | Description | Link |
|----------|-------------|------|
| **Ensembl Genome Browser** | Genome browser for exploring genes, transcripts, variants and regulatory annotations across multiple species. | https://www.ensembl.org |
| **Ensembl Regulation** | Dedicated interface for exploring regulatory features and gene context, supporting epigenomic evidence and regulatory activity across tissues and cell types. | https://regulation.ensembl.org |
| **ENCODE SCREEN** | Browser for exploring ENCODE candidate cis-regulatory elements (cCREs), biosample-specific activity and supporting experimental evidence. | https://screen.wenglab.org |
| **Integrative Genomics Viewer (IGV)** | Desktop genome browser for interactive visualisation of local and remote genomic datasets. | https://igv.org |
| **IGV-Web** | Browser-based version of IGV that runs without installation. | https://igv.org/app/ |

# Integrative Genomics Viewer (IGV)

The **Integrative Genomics Viewer (IGV)** is a high-performance genome browser developed by the Broad Institute for interactive exploration of genomic and epigenomic datasets.

Throughout this tutorial, IGV will be used to visualise multiple layers of evidence, including:

- Gene annotations
- Regulatory annotations
- Epigenomic signal tracks (bigWig)
- Peak files (BED)
- User-defined genomic regions

Participants will learn how to load, organise and interpret these data during **Session 5: Visualisation with Genome Browsers**.

---

# Installation

We strongly recommend installing **IGV Desktop** before attending the tutorial.

Download IGV from the official website:

https://igv.org/

Installation packages are available for:

- Windows
- macOS
- Linux

Please launch IGV once after installation to verify that it opens correctly.

---

# IGV-Web

If you prefer not to install the desktop application, or cannot install software on your computer, you may use **IGV-Web**, which runs directly in your web browser.

Launch IGV-Web at:

https://igv.org/app/

Most of the tutorial exercises can also be completed using the web version.

# During the tutorial

IGV will be introduced in **Session 5**, where participants will learn how to:

- Load the appropriate reference genome.
- Open local annotation and evidence files.
- Load remote tracks.
- Adjust track display settings.
- Compare signal, peak and annotation tracks.
- Save an IGV session for future use.

No previous experience with IGV is required.

---

# Troubleshooting

If you experience problems launching IGV:

- Ensure that you downloaded the correct version for your operating system.
- Verify that Java is installed if required by your version of IGV.
- Alternatively, use **IGV-Web**, which only requires a modern web browser.
