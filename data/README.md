# Data

This directory contains the datasets used throughout the **ECCB 2026 Tutorial T6: Making the most of cis-regulatory annotations for genome-scale analysis**.

The data have been selected to illustrate how regulatory annotations and supporting epigenomic evidence can be explored using public resources. Unless otherwise stated, the files are subset versions of publicly available datasets chosen to keep the tutorial lightweight and reproducible.


## Data provenance

The tutorial uses publicly available datasets obtained from community resources including:

* Ensembl Regulation
* ENCODE

Where files have been subsetted or reformatted for the purposes of the tutorial, their provenance and any processing steps are documented in the [files_provenance_ECCB-2026-T6](files_provenance_ECCB-2026-T6.xlsx) file.


## Directory structure

```
data/
├── cres_annotations/
├── evidence/
└── query_regions/
```

### `cres_annotations/`

Reference regulatory annotations used during the tutorial.

Currently includes:

* **ENCODE cCREs** (candidate cis-Regulatory Elements)
* **Ensembl Regulatory Features**
* **Fantom 5 enhancers**
* **VISTA enhancers**
* **RefSeq Functional Elements**

These files will be used across different sessions to compare regulatory annotations generated by different resources, illustrate how they can be queried and visualised, and analyse loci of interest.

### `evidence/`

Supporting epigenomic datasets associated with the regulatory annotations.

The datasets include representative assays such as:

* ATAC-seq
* DNase-seq
* H3K4me3 ChIP-seq
* H3K27ac ChIP-seq
* H3K4me1 ChIP-seq

Data are organised first by resource and then by biological context.

Current biological contexts include:

* **HCT116**: [Human colorectal carcinoma cell line](https://www.ebi.ac.uk/ols4/ontologies/efo/classes?short_form=EFO_0002824).
* **Forebrain E13.5**: Mus musculus strain B6NCrl forebrain tissue embryo, 13.5 days.

These datasets are used to demonstrate how experimental evidence supports regulatory annotations and how genomic loci can be explored using genome browsers and programmatic analyses.

### `query_regions/`

Genomic regions investigated during the hands-on exercises.

These files contain the loci that participants will use throughout the tutorial when comparing annotations, exploring epigenomic evidence, and interpreting regulatory elements.

## Notes

The datasets included in this repository are intended exclusively for educational purposes. They represent a subset of the original public resources and are provided to support the practical exercises of the tutorial.

Some IGV screenshots included in Session 1 and Session 5 slides show the use of the GENCODE Basic gene annotation file for Human (GRCh38) Release 48. This file has not been added to this repository and it is not mandatory for completing the tutorial. If you are interested, it can be downloaded from the [GENCODE website](https://www.gencodegenes.org/human/release_48.html).
