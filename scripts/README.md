# Scripts

This directory contains helper scripts used to prepare and manipulate some of the regulatory annotation and evidence files distributed with this tutorial.

These scripts are provided to ensure **reproducibility** of the tutorial materials by documenting the processing steps applied to publicly available datasets.

> **Note**
> Running these scripts is **not required** to complete the tutorial. The processed files generated by these workflows are already included in the [data/](../data/) directory.

## Contents

### Bash

| Script | Description |
|---------|-------------|
| `preprocessing/bash/liftover_mm10_to_GRCm39.sh` | Downloads the ENCODE cCREs for mm10, the UCSC **liftOver** tool and the **mm10ToGRCm39** chain file, then converts the ENCODE mouse cCRE annotations from the mm10 assembly to GRCm39. |
| `preprocessing/bash/bigBed_to_bed_EnsReg_evidence_files.sh` | Downloads the UCSC **bigBedToBed** utility and converts every `.bb` file below the current directory into a `.bed` file alongside it. |
| `preprocessing/bash/extract_RefSeqFE_annotations.sh` | Extracts `RefSeqFE` annotations from the RefSeq GRCh38 GFF file, replaces RefSeq accession chromosome names with chromosome names, removes `biological_region` features, and writes a gzip-compressed GFF file. |

### R

| Script | Description |
|---------|-------------|
| `preprocessing/R/GRCh38-cCREs-coloring.R` | Converts ENCODE human cCRE annotations (GRCh38) into a BED9 file with colour definitions for visualisation in genome browsers such as IGV. |
| `preprocessing/R/GRCm39-cCREs-coloring.R` | Converts ENCODE mouse cCRE annotations (GRCm39) into a coloured BED9 file for genome browser visualisation. |
| `preprocessing/R/mm10-cCREs-coloring.R` | Converts ENCODE mouse cCRE annotations (mm10) into a coloured BED9 file for genome browser visualisation. |

## Purpose

The preprocessing scripts perform two main tasks:

1. Convert the ENCODE mouse cCRE annotations from **mm10** to **GRCm39** using UCSC **liftOver**.
2. Convert ENCODE cCRE BED files into **BED9** format by assigning colours to each cCRE class according to the ENCODE visualisation scheme.
3. Convert Ensembl BigBed files to BED files. Mainly for open chromatin files that will be used in the hands-on activity of Session 4. 
4. Extract and prepare RefSeqFE annotations for use as regulatory annotation tracks.

The resulting CREs files are suitable for visualisation in genome browsers such as **IGV** and the **UCSC Genome Browser**, making easier to distinguish between CRE types during the hands-on exercises.

## Running the scripts

The scripts use relative input and output paths. Run them from the directory that contains the relevant input files, rather than from the repository root.

### Convert mm10 cCREs to GRCm39

From the repository root:

```bash
cd data/cres_annotation/ENCODE
bash ../../../scripts/preprocessing/bash/liftover_mm10_to_GRCm39.sh
```

This creates the intermediate files `mm10-cCREs_LOGRCm39.bed` and
`mm10-cCREs.unmapped.bed`. The corresponding coloured GRCm39 BED9 file can
then be created with:

```bash
Rscript ../../../scripts/preprocessing/R/GRCm39-cCREs-coloring.R
```

The liftover script downloads `mm10-cCREs.bed`, `liftOver`, and
`mm10ToMm39.over.chain.gz` if they are not already present in the working
directory.

### Convert Ensembl Regulation BigBed files to BED

From the repository root:

```bash
cd data/evidence/Ensembl_Regulation
bash ../../../scripts/preprocessing/bash/bigBed_to_bed_EnsReg_evidence_files.sh
```

The command creates a `.bed` file next to each `.bb` file, including files in
the HCT116 and `forebrain-E13.5` subdirectories. The downloaded `bigBedToBed`
utility is removed when the conversion finishes. This repository contains the BED version of open chromatin files only which are the ones used in the Session 4 hands-on.

### Extract RefSeqFE annotations

From the repository root:

```bash
bash scripts/preprocessing/bash/extract_RefSeqFE_annotations.sh
```

The script reads:

```text
data/cres_annotation/RefSeq/GCF_000001405.40_GRCh38.p14_genomic.gff
```

It uses the `RefSeq` `region` rows to replace accession sequence names such as
`NC_000001.11` with chromosome names such as `1`, retains rows whose source
column is `RefSeqFE`, and removes rows whose feature type is
`biological_region`. The output is written to:

```text
data/cres_annotation/RefSeq/GCF_000001405.40_GRCh38.p14_genomic.RefSeqFE.gff.gz
```

### Create coloured ENCODE cCRE BED9 files

Run the relevant R script from the directory containing its input BED file:

```bash
cd data/cres_annotation/ENCODE
Rscript ../../../scripts/preprocessing/R/GRCh38-cCREs-coloring.R
Rscript ../../../scripts/preprocessing/R/mm10-cCREs-coloring.R
Rscript ../../../scripts/preprocessing/R/GRCm39-cCREs-coloring.R
```

The GRCh38 and mm10 scripts expect the original `GRCh38-cCREs.bed` and
`mm10-cCREs.bed` files. The GRCm39 script expects the intermediate
`mm10-cCREs_LOGRCm39.bed` file produced by the liftover script.

## Colour scheme

The following ENCODE cCRE classes are currently supported:

| cCRE class | Description |
|------------|-------------|
| PLS | Promoter-like signature |
| pELS | Proximal enhancer-like signature |
| dELS | Distal enhancer-like signature |
| CA | Chromatin accessible |
| CA-CTCF | Chromatin accessible with CTCF binding |
| CA-H3K4me3 | Chromatin accessible with promoter-associated H3K4me3 |
| CA-TF | Chromatin accessible with transcription factor binding |
| TF | Transcription factor binding site |

The colours follow the ENCODE cCRE visualisation conventions used by the SCREEN portal.

## Requirements

### Bash

- `wget`
- `awk`
- `gzip`
- UCSC `liftOver` (downloaded automatically by `liftover_mm10_to_GRCm39.sh`)
- UCSC `bigBedToBed` (downloaded automatically by `bigBed_to_bed_EnsReg_evidence_files.sh`)

> **Note**
> This script was developed and tested on a Linux system. It downloads the Linux version of the UCSC liftOver executable and therefore will not work on macOS or Windows without modification.

### R

- R with `Rscript`
- `dplyr`

## Input

The scripts expect the following ENCODE cCRE annotation files:

| File | Source |
|------|--------|
| `GRCh38-cCREs.bed` | https://downloads.wenglab.org/Registry-V4/GRCh38-cCREs.bed |
| `mm10-cCREs.bed` | https://downloads.wenglab.org/Registry-V4/mm10-cCREs.bed |

The `liftover_mm10_to_GRCm39.sh` script generates:

- `mm10-cCREs_LOGRCm39.bed`
- `mm10-cCREs.unmapped.bed`

which is subsequently used by `GRCm39-cCREs-coloring.R`.

## Output

The preprocessing workflows generate coloured **BED9** files suitable for visualisation in genome browsers. The files are available in the [data/cres_annotation/ENCODE/](../data/cres_annotation/ENCODE/) folder. The BigBed conversion workflow generates BED files next to the source files under [data/evidence/Ensembl_Regulation/](../data/evidence/Ensembl_Regulation/).
